## Priority fix list

### P0 — fix before the next billing cycle / big session
1. **Stripe webhook ignores DB errors** (`app/api/webhooks/stripe/route.ts:203` and 5 more writes): supabase-js does not throw, so a failed membership insert after payment returns 200 to Stripe — paid customer, no membership, no retry, no alert. Check `{ error }` on every write; return 500 on failure.
2. **GHL `payment_success` is non-idempotent** (`app/api/webhooks/ghl/route.ts:115` + `lib/membership.ts:217`): each delivery stacks months onto current expiry with no event dedupe — a double-fire grants free months. Ledger the event id before applying.
3. **Reminders cron breaks at large sessions** (`app/api/cron/reminders/route.ts:66-88`): dedupe/prefs lookups pass the full roster to `.in()` — past ~500-1,000 enrollees the query fails and the cron mass re-emails the roster every 5 minutes. Chunk lookups; abort the session's send if dedupe errors. Companion bug at `:293-302`: drop-in reminders silently truncate at 500 opt-ins.
4. **No timeouts on outbound calls** (stripe/ghl/zoom/mux/podcast/ai libs): one hung socket pins a webhook past Stripe's delivery window or a cron for its full 300s. Add `AbortSignal.timeout(10000)` everywhere.
5. **GHL send throws crash whole crons** (`lib/notifications.ts:242,302`): wrap the fetch; a GHL outage currently kills reminders/dunning/report runs at the first member and suppresses even in-app fallbacks.

### P1 — this month
6. **SSO handoff can mint admin logins** (`app/api/sso/handoff/route.ts:454`): refuse admin-account targets, mirroring `getLoginLink()`.
7. **Dunning advances steps on failed sends** (`app/api/cron/dunning/route.ts:143`): a week of GHL 429s burns all 3 warnings undelivered, then access is cut unwarned. Journal only delivered/permanent-failure steps.
8. **Missed-checkout heal can't heal public signups** (`webhooks/stripe:287` + `app/join/actions.ts:105`): stamp signup email into subscription metadata.
9. **Contrast: add a dark secondary-text token** — `--mid-gray` (#b0a99e) and gold (#B8965A) as text on light surfaces fail WCAG AA in hundreds of places (globals.css tokens + inline uses). Introduce `--ink-secondary` (~#6b6558) and darkened gold text (~#8a6f3d) for light backgrounds.
10. **Security headers on both apps**: neither site sends X-Frame-Options / CSP frame-ancestors / X-Content-Type-Options / Referrer-Policy (HSTS only). One `headers()` block in next.config each.
11. **Cron monitoring blind spots**: summaries GET never records its heartbeat; podcast cron missing from `CRON_EXPECTATIONS`; both can die invisibly.
12. **Email enumeration via /join** (`app/join/actions.ts:64`): return a neutral response for existing accounts.
13. **Mobile: search unreachable** (topbar-search hidden ≤640px with no alternative) and **live-notes drawer button off-screen on phones** (`globals.css:1633`).

### P2 — scheduled hardening
14. RLS performance migration: wrap `auth.uid()` in `(select auth.uid())` across the 41 flagged policies; consolidate the 101 overlapping permissive policies; index the 20 unindexed FKs (advisor list saved).
15. Profile page waterfall → Promise.all (12-15 sequential round-trips today); request-cache `auth.getUser()`; unstable_cache the access matrix.
16. Unbounded catalog queries: sessions list (all seasons), library double full-table scan, podcast episodes with full notes in every payload — add windows/limits.
17. Zoom signature route: collapse ~12 queries to one service-role fetch (session-start burst path).
18. Announcement/reminder fan-out: bounded concurrency (5-10 parallel) + batched ledger writes; today ~700-900 members/run ceiling.
19. Serve sponsor/ad images through next/image (27 raw img uses member-facing).
20. Screen-reader live regions on member feedback (enroll/notes/login/ask-the-show); aria-pressed on filter chips; Escape-to-close on topbar menus; text equivalent for online dots.
21. Gift pause/ledger ordering (`lib/onboarding.ts:459`); anonymous crash reports on /join recorded nowhere; monthly report SENT_KEY stamped even when 0 emailed; rate limiter fail-open backstop; caps on podcast questions/testimonials; certificate download to require active membership; lapsed-`VERCEL`-only fail-open gate → NODE_ENV.
22. Flow/utility polish: padlocked unlaunched tabs route to a page that can't sell them; certificates CTA points at a delisted section; calendar legend mislabels two categories; "Session full" reads as cancelled with no next step; podcast + member directory absent from search; per-row "Pull attendance" admin action.

## Infrastructure evidence (production)

- Database advisors (performance): 41 `auth_rls_initplan` warnings, 101 `multiple_permissive_policies`, 20 unindexed FKs, 14 unused indexes, auth pool at 10 connections.
